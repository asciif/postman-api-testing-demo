# Postman API Testing Demo

This repository demonstrates my ability to conduct API testing and write basic automated assertions using **Postman**.

## Features Tested
* **GET Requests:** Verifying endpoint availability and response times.
* **Status Code Assertions:** Ensuring APIs return correct HTTP status codes (e.g., 200 OK).
* **Schema Validation:** Parsing JSON responses and validating data structures using JavaScript inside Postman `Tests` tab.

## How to use
1. Download the `Reqres_API_Tests.postman_collection.json` file.
2. Open Postman and click `Import`.
3. Select the downloaded file and run the collection.
